# MIZAN — Heir Madhhab Support Guide

## Statuses

- `SUPPORTED`: Heir count can be entered and processed under this madhhab.
- `NOT_SUPPORTED`: Relationship is not supported as an input under this release.
- `NOT_YET_MODELLED`: Pending scholar review (e.g. `MATERNAL_GRANDFATHER`).
- `REVIEW_REQUIRED`: Referred for scholar review.

---

## Directives (Q2 Safeguards)

`MATERNAL_GRANDFATHER` is marked `NOT_YET_MODELLED`. It does not participate in the calculation path or affect eligibility, Hijab, shares, or totals.
