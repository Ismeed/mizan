# MIZAN — Heir Group Standard

## Overview

Heir groups define reusable collections of canonical heir IDs for Hijab rules, eligibility checks, and report presentation.

---

## Group Identifiers

`SPOUSES`, `PARENTS`, `GRANDPARENTS`, `ASCENDANTS`, `IMMEDIATE_DESCENDANTS`, `DESCENDANTS`, `MALE_DESCENDANTS`, `FEMALE_DESCENDANTS`, `FULL_SIBLINGS`, `PATERNAL_SIBLINGS`, `MATERNAL_SIBLINGS`, `SIBLINGS`, `SIBLINGS_DESCENDANTS`, `PATERNAL_UNCLES`, `PATERNAL_UNCLES_DESCENDANTS`, `COLLATERAL_RELATIVES`
