# Evidence Citation Guide (Phase 4)

## Citation Formatting Service

The `EvidenceCitationService` provides deterministic formatting across 6 contexts:

1. **Short Citation**: `Quran 4:11`, `Bukhari 1454`, `Al-Mudawwanah 2:45`
2. **Full Citation**: `Surah An-Nisa, 4:11`, `Sahih al-Bukhari, Hadith 1454`
3. **Academic Export**: Includes publisher, edition, and attribution.
4. **PDF Reports**: Formatted with permanent evidence ID references.
5. **AI Assistant**: Display payload for AI context card.
6. **Mobile UI**: Minimalist card citation display.
