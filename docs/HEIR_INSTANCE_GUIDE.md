# MIZAN — Heir Instance Guide

## Structure

```json
{
  "heirInstanceId": "heir_inst_001",
  "heirId": "FULL_BROTHER",
  "entityVersion": "1.0.0",
  "count": 2,
  "optionalPersons": [{ "displayName": "Zayd" }]
}
```

Personal names (`"Zayd"`) are stored in `optionalPersons` and NEVER replace the canonical heir ID `FULL_BROTHER`.
