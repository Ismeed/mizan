# Scholarly Reference Standard (Phase 4)

## Contemporary & Institutional Sources

Covers contemporary books, peer-reviewed journal articles, Sharia board standards (AAOIFI, OIC Fiqh Academy), and legal maxims.

ID Format: `SCHOLARLY-<SOURCE_CODE>-<SEQUENCE>` or `LEGAL_MAXIM-<SOURCE_CODE>-<SEQUENCE>`.

Primary classical sources, secondary scholarly explanations, and institutional standards are explicitly categorized to prevent improper equivalence.
