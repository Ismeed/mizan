# MIZAN Report Template Authoring Guide (Phase 14)

Report templates define layout, typography, citation policies, and section sequence.

## Rules for Template Authors

1. **Immutable Sequence**: Standard production templates MUST preserve the 12 canonical section IDs in exact order.
2. **Content Blocks**: Templates register allowed content block types (`MIRATH_HEIR_TABLE`, `ZAKAT_CATEGORY_TABLE`, `MONETARY_TOTAL_BLOCK`, etc.).
3. **No Executive Code**: Templates must not execute code or perform mathematical operations.
4. **Governance**: New template versions require Shariah review, accessibility validation, and technical approval before publication (`APPROVED`).
