# MIZAN Standard Report Section Sequence (Phase 14)

Every Mirath and Zakat report generated by MIZAN MUST conform to this 12-section sequence in exact order:

1. `REPORT_IDENTITY` — Identification metadata (Report ID, module, calculation date, selected madhhab).
2. `CALCULATION_PROFILE` — Immutable execution profile snapshot.
3. `INPUT_SUMMARY` — Summary of user-provided facts and assets evaluated.
4. `VALIDATION_AND_SCOPE` — Input validation status and automated rule engine coverage scope.
5. `RESULT_SUMMARY` — Executive summary of outcomes and key obligations.
6. `DETAILED_BREAKDOWN` — Itemized step-by-step breakdown of shares or zakat categories.
7. `EXCLUDED_AND_REVIEW_ITEMS` — Blocked heirs (Hijab), exempt items, items below nisab, items requiring review.
8. `EVIDENCE_AND_EXPLANATIONS` — Formatted evidence citations (1. Qur'an, 2. Hadith, 3. Fiqh) and explanations.
9. `TOTALS_AND_RECONCILIATION` — Sum totals, exact fractions, rounding adjustments, and reconciliation checks.
10. `WARNINGS_AND_ACTIONS` — System disclosures, currency conversion notes, and required user actions.
11. `TECHNICAL_AND_AUDIT_DETAILS` — Checksums, snapshot IDs, trace IDs, and rule engine versions.
12. `DECLARATION_AND_CLOSING` — Report declaration, Shariah board attribution, and QR verification reference.
