# PDF Report Exporter & Viewer

## Purpose
The primary purpose of PDF Report Exporter & Viewer is to provide users with seamless access to MIZAN features, workflows, and calculations.

## Who Uses It
- All registered users, guests, scholars, and administrators seeking assistance with pdf report exporter & viewer.

## How to Access It
- Can be accessed by navigating to route `/reports/pdf` or tapping the designated card/tab in MIZAN.

## Navigation Path
- `Dashboard -> PDF Report Exporter & Viewer (/reports/pdf)`

## Buttons & Icons
- **Primary Button**: Action button to proceed with workflow.
- **Header Back Icon**: Return to previous screen.
- **Settings Gear**: Access preferences.

## Available Actions
- Perform calculations, view breakdowns, export PDFs, edit options, or consult the AI Assistant.

## Input Fields & Validation Rules
- Required fields must be completed. Numerical inputs must be non-negative.

## Possible Errors & Success Messages
- **Success**: "Action completed successfully."
- **Error**: "Invalid input or network connection error."

## Related Screens
- Dashboard, Settings, AI Assistant, History, Profile.

## Frequently Asked Questions
