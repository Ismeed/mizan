# Application Settings & Fiqh Preferences

## Purpose
The primary purpose of Application Settings & Fiqh Preferences is to provide users with seamless access to MIZAN features, workflows, and calculations.

## Who Uses It
- All registered users, guests, scholars, and administrators seeking assistance with application settings & fiqh preferences.

## How to Access It
- Can be accessed by navigating to route `/settings` or tapping the designated card/tab in MIZAN.

## Navigation Path
- `Dashboard -> Application Settings & Fiqh Preferences (/settings)`

- **Primary Button**: Action button to proceed with workflow.

- Required fields must be completed. Numerical inputs must be non-negative.
